# 画像処理アルゴリズムの実装

「ディジタル画像処理」のアルゴリズムをいくつか実装してみる．既に知っている，作ったことがある場合はスキップしても良いかもしれない．

## レギュレーション

- 標準ライブラリ以外使用不可
- 言語は何でもOK (推奨はPython)

## タスク

- [ ] 平均値フィルタ
- [ ] ガウシアンフィルタ
- [ ] メディアンフィルタ
- [ ] 大津の二値化
- [ ] 膨張・縮小
- [ ] Sobelフィルタ
- [ ] Cannyフィルタ

アルゴリズムは自体は，次のタスク「MNISTの手書き文字認識モデルの作成」で使えそうかつ有名なアルゴリズムを北川個人の判断でピックアップしております．他に実装したほうが良いがディジタル画像処理のアルゴリズムがあれば @s.kitagawa にお伝えください，追加しておきます．
